# HLD - High Level Design: Operational Command Center

## Overview
This repository contains the High Level Design (HLD) document for a modern GUI to be built for an existing Python Core system.

## Key Features
- **Modern UI/UX**: Built with React + Vite
- **Real-time Updates**: Server-Sent Events (SSE) for live status
- **Asynchronous Architecture**: RabbitMQ for reliable message queuing
- **Scalable Design**: BFF (Backend for Frontend) pattern with FastAPI

## Architecture Highlights
- **Frontend**: React + Vite
- **BFF**: FastAPI (Python)
- **Message Broker**: RabbitMQ
- **Streaming**: SSE (Server-Sent Events)
